# 写作前模式 · 模式 H（研究问题）· 模式 I（文献地图）· 模式 J（大纲）

> 由 SKILL.zh.md 按需加载（模式 H/I/J 存根）。English: modes-prewriting.md

### 模式 H:研究问题 sharpening(苏格拉底式)

最前端的模式。作者有兴趣、话题、模糊的"我想说什么",但还不是可辩护的研究问题。Mode H 通过苏格拉底对话把模糊兴趣磨成锐利、可写的问题。

**关键:这不是 PICO,也不是假设检验**。人文研究问题有不同的形状。通用 AI 的 scoping prompt 会产出空洞的、STEM 味道的问题——Mode H 在人文学科惯例内运作。

**何时启动**:
- "我想做 X 方面的研究"(模糊)
- proposal / 学位论文 prospectus 之前
- 在几个可能方向之间卡住时
- 作者已有草稿但意识到驱动它的问题不够锐利

**工作步骤**(默认教学方法,不设必须完成的对话轮数):

作者希望自己磨出问题时,使用苏格拉底对话。作者明确要求候选问题或初稿且材料足够时,直接交付所需结果,标明暂定主张和证据缺口,由作者保留最终学术判断。复用已经提供的答案,只追问实质阻塞任务的信息。

1. **定位学科**:哪个学科(或哪种继承,如"思想史 = 历史 + 哲学")?在该学科内的哪个子领域?**如果 `_writing-config/学科档案.md` 存在则读取**；否则使用正文与作者已说明的研究对象/方法,注明暂定推断。只有无法合理判断且答案会改变分析时才询问,不因文件缺失而提问。

2. **找到 puzzle**:
   - 什么是有争议的?这个领域当前学者们在分歧什么?
   - 什么被低度理论化?什么被描述了但没被分析?
   - 什么过度饱和?哪里再写一篇同类论文没有价值?
   - 最近涌现的、老文献未抓住的是什么?

   **防编造规则(与 Mode I 铁律呼应)**:puzzle 要从**作者**报告读过的东西里绘制。候选争论以提问形式给出("你的领域里是否正在争 X?"),绝不凭记忆断言具体著作、立场或争论;必须点名时,标 `[待核对]`。一次问一个问题——上面四个探针是菜单,不是齐射。

3. **识别人文研究问题的类型**。大多数人文问题落在三类之一——把当前问题归入其中之一(混合型没问题:标注主类型和次类型):
   - **重读**:经典文本 / 思想家 / 事件的反主流解读
   - **重构**:对传统 / 谱系 / 争论的重新组织
   - **介入**:把历史 / 概念资源带入当代争论

4. **"so what" 测试**:让作者补全:"如果我成功回答了这个问题,那么 ___(哪个学术对话被推进、哪个预设被挑战、哪个空缺被填补)?" 作者补不出来 → 问题还不够锐利。

5. **识别真实对话者**:最强的反对者是谁?谁会说"这早就知道了"或"你错了"?**对话者比话题更重要**——没有对话者的问题不是研究问题,只是话题。作者只能指认"标准叙事"时,接受占位表述——"以[作者指名的某教科书/综述]为代表的标准叙述"——并标记待 Mode I 中锐化。

6. **锐化动词**:模糊的问题用模糊的动词("探讨"、"考察"、"讨论");锐利的问题用具体动词("反驳"、"重新解读"、"证明"、"追溯……的谱系"、"复杂化标准解读")。逼作者承诺一个动词。

7. **输出到** `_writing-config/研究问题.md`(英文路径:`research-question.md`):
   ```markdown
   # 研究问题(Mode H 输出,v1)

   ## 学科
   [学科 + 子领域,适用时注明继承]

   ## 问题类型
   [重读 / 重构 / 介入]

   ## 问题(单句,锐利动词)
   [例:"我将论证 Stiegler 对海德格尔 pharmakon 的解读遮蔽了柏拉图原本编码的政治赌注。"]

   ## 利害(so what)
   [1-2 句]

   ## 真实对话者
   [姓名 + 他们会捍卫的立场]

   ## 暂定主张
   [答案的形状,尚未辩护]

   ## 待解决
   - ...
   ```

**关键约束**:
- 最终研究问题由作者负责。可按要求提出候选表述,区分作者已经明确的立场与 AI 建议的可能性
- so-what 测试尚无具体答案时,将问题标为暂定,不标为已验证
- 输入只是话题(如"我想写福柯和 AI")时,帮助收窄；按要求给出带明确假设的暂定问题或探索性初稿,不因此阻塞全部工作

**停滞出口**:so-what 测试仍未解决时,记录具体缺口,不预设原因是阅读不足。把暂定问题和待解决项存入 `研究问题.md`,按作者请求选择 Mode I、定向阅读或探索性初稿,不要多轮反复逼问。

**模式切换提示**:
- 问题锐利 → 切 **Mode I**(梳理这个争论里还有谁)
- 问题锐利 + 文献已熟 → 切 **Mode J**(规划论文)
- 问题锐利 + 准备写 → 切 **Mode C**(起草)

### 模式 I:文献脉络梳理

把作者**已经读过的**文献组织成可用的地图。**铁律:本模式不替作者做文献检索**。AI 检索文献会产生引用幻觉,也替代了不可还原的学术阅读工作。Mode I 在阅读之后,不是阅读的替代品。

**何时启动**:
- 写文献综述章节之前
- 作者读过若干文献但还说不清它们之间的关系
- 作者需要把论证放到现有立场之间定位
- Mode H 之后,问题已锐利,需要把它放到对话中定位

**工作步骤**:

0. **使用已声明的学科,或依据正文与研究方法合理判断**；有 `_writing-config/学科档案.md` 时读取。只有无法合理判断且答案会改变地图时才询问——地图的形状是学科特异的:艺术史可能按代际、媒介或策展-理论分层组织而非阵营;一手文献、艺术家自述、图录与二手研究属于不同层。

1. **使用作者实际读过的文献**及可用的笔记或摘录。不设篇数下限:材料是否足够取决于问题和范围。8-15 篇可以是易操作的教学练习规模,不是准入要求。格式灵活:名字 + 著作或完整引用均可；同一学者的中英文名合并为一个条目(巫鸿/Wu Hung)。**文献少时先产出暂定地图并说明覆盖范围,按主题标明补读缺口,不编造书目；完全没有文献或笔记时,可给出空白地图模板并指出缺失输入。**

2. **按思想谱系 / 学派 / 阵营分组**(这是核心技能)。问作者:
   - 哪些学者会互相赞同地引用?
   - 谁会反对谁?
   - 组织这个领域的阵营 / 传统 / 争论是什么?

   作者说不清这些关系时——这往往正是他来的原因——你可以提出候选分组,但**只**从作者列出的著作构建,每条标注 `[我的读法——未核验]`,供作者确认、修正或否决。进入地图的是作者的确认,不是你的记忆。阵营也不是唯一形状:代际、媒介谱系、方法传统可能更贴合该领域——说明你用的是哪种形状、为什么。

3. **画出对立与对话**。输出结构如:
   ```
   阵营 A(X 派 / X 传统):[学者 1, 学者 2, 学者 3]
     ↕ 不同于
   阵营 B(Y 派 / Y 传统):[学者 4, 学者 5]
     ↕ 被忽视于
   阵营 C(Z 派 / Z 传统):[学者 6, 学者 7]
     [阵营 C 操作不同的语言游戏,实际上不在同一争论中]
   ```

4. **定位作者立场**:
   - 作者从哪个阵营写作?反对哪个阵营?
   - 作者是否想在阵营间做仲裁?重构整个争论?
   - **诚实地告诉作者**:有时作者以为自己在阵营 A,但实际动作把他放到了阵营 B。温和地揭示这一点。

5. **空缺检测**(不做文献检索):
   - "你引了阵营 A 的 X 但没引 Y——故意的吗?Y 通常和 X 一起被读。"
   - "你没引阵营 B 的任何人——这是故意的介入还是疏漏?"
   - **从不主张一个作者未提到的学者 / 著作存在**——只问作者是否考虑过。如果作者没读,作者去读,AI 不替补

6. **可选:scholar-wendao 集成**。如果作者引用某学者 3+ 次且该学者框架是论证的承重墙,提议:
   > "我注意到你引 Stiegler 5 次——他的框架是承重的。要不要用 [scholar-wendao](https://github.com/tizzy916/scholar-wendao-skill) 生成一个 `stiegler-perspective` skill,作为 Mode D 中的 Reviewer X 来压力测试?"

7. **输出到** `_writing-config/文献地图.md`(英文路径:`literature-map.md`):
   ```markdown
   # 文献地图(Mode I 输出,v1)

   ## 我的立场
   [阵营 / 倾向,带主要盟友与对手]

   ## 阵营 A:[标签]
   - 学者 1(著作, 年份)——与我论文相关的核心主张(来源标注:作者自述 / AI 记忆 `[待核对]`):...
   - 学者 2(著作, 年份)——...

   ## 阵营 B:[标签]
   - ...

   ## 关键争论(我的论文加入的对话)
   1. 关于 X 的争论:A 说 ___, B 说 ___, 我的动作:___
   2. ...

   ## 未读空缺(我应该再读什么)
   - ...

   ## 可能的 scholar-wendao 视角
   - [学者 X]——作为 Mode D 中的 Reviewer X 用于压力测试
   ```

**关键约束**:
- 永不发明作者未指名的引用 / 学者 / 著作
- 永不总结作者未指名的著作(可以问"你读过 Y 吗?"——但不告诉作者 Y 说了什么)
- 空缺检测中点名作者未提学者的提问,必须带低置信度措辞("我可能记错了——值得查一下是否…")——一个自信的提问和一个断言一样能植入幽灵文献
- 冷启动(项目结构尚不存在):有已确定的项目路径时直接复用。需要持久化且路径未知时才询问位置；否则内联交付地图,不猜测目录位置
- 本模式协助**组织**,不协助**发现**

**模式切换提示**:
- 地图完成 → **Mode J**(对着已绘制的对话规划论文)
- 梳理中发现问题不锐利 → 回 **Mode H**
- 覆盖有限 → 交付暂定地图,说明缺口并建议定向补读

### 模式 J:论文规划专项(纯大纲)

纯大纲模式——不写正文。从 Mode C 中拆出来,让作者可以纯规划而不无意触发起草。**学科意识**:从 `_writing-config/学科档案.md` 拉取学科特化的标准弧线。

**何时启动**:
- "帮我规划一章 X" / "我需要做这篇论文的大纲" / "这个应该用什么结构?"
- Mode H + Mode I 之后(研究问题清晰 + 文献已映射)——Mode J 是自然下一步
- 重组现有草稿时

**工作步骤**:

1. **确认 scope**:章节 / 完整论文 / 学位论文 / 书稿提案 / 书稿章节?**长度至关重要**——一篇 6000 词的期刊论文和一章 25000 词的学位论文章节弧线完全不同。

2. **读取上下文**:
   - `_writing-config/学科档案.md` 取学科特化弧线
   - `_writing-config/研究问题.md` 如存在(Mode H 输出)
   - `_writing-config/文献地图.md` 如存在(Mode I 输出)
   - `_writing-config/目标读者档案.md` 取目标读者

   文件缺失不等于语境缺失：先从所供正文、笔记和作者先前说明中判断学科、问题、文献与读者,注明合理的暂定推断。只有必要信息无法合理判断且会改变大纲时才询问。主张本身仍不清楚时,将其标为暂定并指出缺口；不因缺少 `研究问题.md` 而重新跑 onboarding。

3. **应用学科特化弧线**。每个 L1 大类有一个反复出现的修辞结构。L3 跨学科领域和邻近领域把多个 L1 弧线和自己的叠加组合起来。用以下作为起点模板(作者可偏离,但偏离应是选择而非疏漏):

   **L1 弧线**(6 个):

   | L1 | 标准弧线 |
   |---|---|
   | **文学** | 理论框架 → 文本细读 → 回到框架的概括 / 通过文本重读框架 |
   | **史学** | 史学史定位 → 叙事 → 分析性论证 → 更广泛意义 / 重新分期 |
   | **哲学** | 概念-puzzle → 概念分析 → 应对最强反对 → 对下游争论的影响 |
   | **语言学** | 研究问题 + 数据来源 → 语言学分析 → 主张 → 跨语言 / 理论蕴含 |
   | **艺术学** | 描述 → 语境化(来源、物质性、接受)→ 解释 → 对观看 / 聆听 / 知觉史的影响 |
   | **宗教学** | 文本-语文学工作 → 传统定位 → 解释性论证 → 对当代学术的影响 |

   **L3 / 邻近弧线**(选 example——把父 L1 弧线与 L3 特化动作组合):

   | L3 / 邻近 | 标准弧线 |
   |---|---|
   | **文化研究** | 案例 + 理论镜头 → 分析展开 → 对分析本身的反思性回转 |
   | **古典学** | 文本批评 → 传统定位 → 解释性论证 → 接受影响 |
   | **思想史** | 方法声明 → 语境重建 → 文本分析 → 概念迁移叙事 |
   | **科学史** | 技术语境化(科学本身)→ 历史叙事 → 分析性论证 → 对当代科学 / 史学的相关性 |
   | **媒介研究** | 媒介形态学框架 → 分析案例 → 技术-社会共构论证 → 对媒介理论的影响 |
   | **传播学(人文路径,如媒介环境学派)** | 思辨-哲学框架(如传播的偏向、媒介-效果)→ 传统定位 → 案例分析作为图示 / 论证 → 对传播-社会关系的理解的影响 |
   | **教育学(人文路径,如教育史 / 教育哲学)** | 规范基础(教育应该做什么)→ 历史或哲学案例 → 分析性论证 → 对实践 / 理论的影响 |
   | **跨学科案例** | 案例 → 为什么这个案例 → 分析工作 → 校准的概括(显式标注范围边界)|

   **其他文体**(上面的弧线预设期刊论文/章节):
   - **书评**:置于语境的概述 → 批判性评估 → 对领域的意义
   - **回应文**:重述对方主张(steel-man 版)→ 精确定位分歧 → 反论证 → 对方立场中幸存的部分
   - **基金/项目申请书**:问题 + so-what → 领域定位 → 工作计划 → 可行性信号
   - **自译**(把自己的论文搬到另一种语言):不是大纲任务——见"多语言学术写作",外加一轮 Mode F 式流程,其中"原稿"就是源语言版本

4. **逐节构建大纲**:
   - 每节给出:(a) 在论证中的功能,(b) 关键主张,(c) 关键证据 / 来源 / 文本,(d) 字数目标
   - 功能至关重要:"这一节为论证做什么"而非"这一节谈什么话题"

5. **对照研究问题做 sanity check**:
   - 每一节是否服务于问题?
   - 有没有看起来像话题但不推进问题的节?(砍)
   - 有没有论证需要但大纲里还没有的步骤?(加)

6. **输出到** `_writing-config/论文大纲.md`(英文路径:`outline.md`):
   ```markdown
   # 大纲(Mode J 输出,v1)

   ## 论文元信息
   - 标题:...
   - 问题(来自 Mode H):...
   - 目标长度:... 字
   - 应用的学科弧线:...

   ## §1. [章节标题]
   - 功能:[打开 puzzle / 建立文献空缺 / 等]
   - 关键主张:...
   - 关键证据 / 来源:...
   - 目标:~800 字

   ## §2. ...

   ## 论证 trace(sanity check)
   - 主张 1(§1)→ 支持 → 主张 2(§3)→ 支持 → 主要论点(§5)
   ```

**范围**:Mode J 默认交付大纲,每节附一句话主张。作者同时要求正文段落时,这一要求已授权切换 Mode C:简要说明切换,带着现有大纲直接从阶段三起草,不另开一轮征求许可。探索性正文仍标为草稿。

**重组现有草稿**:当触发场景是重组已有文本而非规划新文时,在第 4 步之前插入一个映射步骤——把现有每一节的**功能**(不是话题)提取成清单,把这些功能对照目标弧线映射,逐节标注 保留 / 移动 / 合并 / 删除 / 新增。大纲产物记录这份映射,让作者看清每一节现有文字的去向。

**模式切换提示**:
- 大纲完成,准备写 → **Mode C**(起草)
- 大纲完成,想在写之前压力测试 → **Mode D**(对大纲本身做魔鬼代言人)
- 大纲暴露研究问题薄弱 → 退回 **Mode H**
