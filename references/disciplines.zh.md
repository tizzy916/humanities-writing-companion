# 人文学科写作的特殊维度 · 完整维度表

> 由 SKILL.zh.md 按需加载。路由协议在 SKILL.zh.md 中；本文件是它的载荷。English: disciplines.md

### L1 · 人文学科六个一级大类

#### L1.1 · 文学

**研究对象**:文本(诗、小说、戏剧、散文、回忆录、混合文体)。

**重点关切**:

- **文本细读 vs 诠释**:细读是否支撑了诠释主张,还是诠释飘离了文本?每个诠释性主张应有文本锚点。
- **理论脚手架**:使用理论框架(精神分析、后殖民、解构等)时,框架是否照亮了文本,还是文本沦为框架的借口?
- **引用作为证据**:被引段落是否真的有证据价值,还是装饰性?引用后的分析是否进入引文内部,还是只是绕着转?
- **作者 / 隐含作者 / 叙述者区分**:尤其在叙事文本中——是否混淆了作者、叙述者、人物?
- **文体意识**:是否尊重文体约定,或反读?如反读,是否通过细致关注赢得了反读的资格?
- **形式-意义贴合**:形式特征(韵律、叙述、结构)是否被读出意义,还是只被当作装饰?
- **互文性**:回声、用典、源文本是否被识别和分析,而不仅是被发现?

#### L1.2 · 史学

**研究对象**:过去的事件、人物、社会、结构。

**重点关切**:

- **因果推理**:叙事中隐含的因果关系是否经得起推敲?是否把时间先后偷换成因果?
- **史料处理**:一手 vs 二手?归属是否清楚?史料偏倚(行动者自身希望被怎样记住的利益)是否被考虑?
- **选择性偏差**:叙事是否有意无意省略了不利于论点的证据?
- **时代错置**:是否用当代范畴套用历史行动者?"知识分子"、"国家"、"个人"、"公众"这些范畴在它们的现代意义不存在的时期使用时有时代错置风险。
- **叙事 vs 分析比例**:是否陷入"讲故事"而忘了"做分析"?
- **反事实压力**:如说"X 导致了 Y",假设 X 不存在——这个因果断言是否仍站得住,还是只是编年史?
- **史学史定位**:这一章与哪个史学传统对话或延伸?(Annales?Cambridge School?Subaltern Studies?马克思主义?新文化史?)

#### L1.3 · 哲学

**研究对象**:概念、论证、规范命题。

**重点关切**:

- **概念推演严密性**:从前提到结论的每一步是否都有交代?有无隐藏步骤?
- **概念辨析充分性**:关键概念是否界定清晰?概念间的区分是否站得住(不只是字面区分)?
- **跨理论移植**:把一个思想家的概念嫁接到另一个框架时,原始含义是否被改变?改变是否被承认?
- **最强反对的 steel-man**:最强反对是什么?论文是否正面回应,还是只与较弱反对交锋(稻草人)?
- **抽象-具体的呼吸**:是否有长段纯抽象缺少例证?(例证不只是图示——它们测试抽象断言是否有咬合力)
- **诠释 vs 介入**:重构思想家 X 说了什么,还是借 X 论证新立场?两者证据标准不同——诠释要求文本忠实;介入要求哲学可辩护性。
- **模态范围**:说"必然"时是逻辑必然、形而上必然、法则必然,还是道德必然?混淆是常见基础层失败。

#### L1.4 · 语言学

**研究对象**:语言结构与使用。

**重点关切**:

- **数据来源披露**:Corpus?母语者直觉?启发实验?自然观察?各有不同认识论地位——人文式语言学写作应明示。
- **形式 vs 功能**:这一章是结构性主张(关于形式)还是使用性主张(关于功能)?两者不应混淆,但可以互相照亮。
- **描述 vs 规定**:用法被描述时,是描述还是规定?人文式语言学通常侧重描述,但做规定动作时应承认。
- **跨语言主张范围**:主张是关于此语言、此语系、还是人类语言一般?各范围需不同证据。
- **语言学 vs 文学维度**:做文学文本工作时,语言学主张(关于结构或用法)与文学主张(关于意义、效果、意图)应区分。
- **历时 vs 共时**:历史语言学主张与共时结构主张方法不同。章节是否明示在做哪种?

#### L1.5 · 艺术学

**研究对象**:跨媒介的艺术作品——绘画、雕塑、音乐、电影、建筑、表演、设计等。

**重点关切**:

- **描述 vs 诠释**:形式描述(构图、材质、技法、图像志、声音、动作)是否支撑诠释?两者应在章节结构上清晰可分。
- **来源与断代**:归属断言是有证据支撑还是依赖传统 / 目录约定?
- **物质性**:章节是否触及作品的媒介特异物质条件(颜料、大理石、胶片、声音录制、数字载体),还是把所有艺术当作抽象内容?
- **语境化**:赞助、生产条件、原始观看 / 聆听语境——是被当作意义的构成性要素,还是背景装饰?
- **接受史**:作品的后世接受是否与原始语境区分?是否标注时代错置的解读?
- **写作中的视 / 听觉证据**:图注 / 谱例 / 镜头描述是否在做分析工作,还是只图示已说过的?
- **媒介特异形式分析**:音乐的形式词汇不同于电影、不同于绘画。章节是否使用了与媒介匹配的词汇?

#### L1.6 · 宗教学

**研究对象**:宗教传统、文本、实践、制度。

**重点关切**:

- **源语严谨**:引用希腊文、拉丁文、希伯来文、阿拉伯文、梵文、巴利文、文言文等文本时,译文是否对照原文核查?翻译选择是诠释性的地方是否标注?
- **传统意识**:在漫长诠释传统内(保罗研究、柏拉图学、儒家经学、古兰经注),章节立场是否相对于既有流派被定位?
- **内 / 外位置(emic vs etic)**:作者对传统的立场(信奉、不可知、批判、比较)是否在影响诠释处被承认?忽视 emic 的 etic 主张可能误读;未被 etic 距离分析的 emic 主张可能变护教。
- **跨传统比较**:做比较断言时,被比较范畴是否在各自传统内部被定义,而不只是从比较框架定义?"神秘主义"、"救赎"、"仪式"在不同传统意义不同。
- **实践 vs 文本**:章节是否在生活实践更相关处偏重了文本来源,或反之?

### L2 · 子学科继承

子学科**继承父 L1 的全部关切**。作者 onboarding 可声明额外的子学科特化约束(如 古代文学 典型加入语文学-文本关切;经济史 加入量化史料处理;现象学 加入第一人称方法论反思性)。把声明的子学科约束当作**叠加**,而非替换。

skill 应识别的常见子学科特化叠加(声明时):

- **文学**:古代文学 → 语文学关切 + 写本传统 · 比较文学 → 翻译理论 + 跨传统方法 · 文学理论 → 关于阅读实践的元层反思
- **史学**:经济史 → 量化史料处理 + 经济学熟悉度 · 思想史 → 见 L3 · 城市史 → 空间推理 + 比较城市学
- **哲学**:中国哲学 → 经典文本诠释 + 传统 · 分析哲学 → 形式精度 + 思想实验方法 · 大陆哲学 → 谱系方法 + 传统内词汇
- **艺术学**:艺术史 → 见 L1.5 强调 · 音乐学 → 音乐分析词汇 + 读谱 · 电影学 → 镜头分析 + 生产语境

作者子学科不在此列时,先从正文与作者已说明的方法判断 L1 之外的约束；只有相关约束无法合理判断且会改变分析时才询问。

### L3 · 跨学科领域

每个 L3 entry 继承**所有列出父 L1 的方法论维度** + **L3 特化叠加**(如下)。

#### L3.1 · 文化研究

**继承**:文学 + 史学 + 社会学(人文导向)。

**L3 特化叠加**:

- **文化对象分析**:对象(电影、时尚、仪式、媒介实践)是被读出其所显示的内容,还是被投射?
- **权力-知识框架**:援引权力(福柯式、马克思主义、后殖民)时,具体机制是否阐明,还是"权力"被当成魔杖?
- **位置性**:章节是否承认作者相对于文化对象的位置?这种承认是实质性还是套话?
- **概括范围**:从分析的案例,对更广泛文化形态做什么断言?这种推理步骤是否辩护?
- **实证-诠释边界**:用了实证材料(访谈、民族志、档案),从材料到断言的诠释步骤是否清晰?

#### L3.2 · 古典学

**继承**:文学 + 史学 + 哲学 + 宗教学 + 考古学。

**L3 特化叠加**:

- **文本批评**:写本传统是否被承认?与诠释相关的文本异文是否讨论?
- **语文学严谨**:翻译选择是否辩护?论证转折于具体词时是否核对原文?
- **接受史**:作品后世接受(中世纪、近代、现代)是否与古代语境区分?章节自身的"现代镜片"是否承认?

#### L3.3 · 思想史

**继承**:史学 + 哲学。

**L3 特化叠加**:

- **方法声明**:章节做的是 Begriffsgeschichte(概念史,Koselleck)、Cambridge School(语境主义,Skinner / Pocock)、histoire des mentalités,还是其他?各有不同证据标准。
- **语境 vs 文本平衡**:章节是在语境中读文本,还是把语境强加于文本?两种错误都常见。
- **避免现时主义**:章节是用现在的关切评判过去思想家,还是重建他们实际面对的问题空间?
- **概念迁移**:概念跨越时期 / 传统(如中世纪 → 近代;希腊 → 阿拉伯 → 拉丁)时,迁移代价是否被追踪?

#### L3.4 · 科学史

**继承**:史学 + 科学 + 哲学。(也服务科学技术学/STS 工作——同一继承链,材料涉及当代技术科学时叠加媒介研究 overlay。)

**L3 特化叠加**:

- **内史 vs 外史**:章节做内史(科学的概念发展)还是外史(产生科学的社会条件)?或论证它们不可分?
- **辉格史警惕**:章节是否按当下标准读过去的科学(即作为通向当前知识的进军)?不可避免时,是否承认这一框架?
- **技术准确性**:章节是否真的理解所历史化的科学?把科学搞错的科学史很快失去可信度。
- **案例研究校准**:为什么是这个案例?它能照亮什么不同案例做不到的?(交叉链接案例分析附录)

#### L3.5 · 媒介研究

**继承**:文学 + 文化研究 + 技术哲学。

**L3 特化叠加**:

- **媒介形态学**:不同媒介有不同认识论。章节是否把媒介当作实质变量,还是只当通道?
- **接受研究**:章节是关于媒介如何被接受的主张,还是只关于如何被生产?各需不同证据。
- **技术-社会共构**:技术被当作决定性、社会建构的,还是共同构成的?章节应明示立场。

#### L3.6 · 数字人文

**继承**:任一 L1 + 计算。

**L3 特化叠加**:

- **数据可重复性**:数据来源是否文档化?另一位研究者能否重现分析?
- **工具透明**:算法 / 工具做什么?其假设是否披露?
- **算法偏倚**:计算工具的偏倚(如主题模型的聚类假设、嵌入的训练 corpus)是否被承认为塑造发现?
- **方法论披露**:计算方法的选择是否辩护,而不只是部署?

#### L3.7 · 性别研究

**继承**:文学 + 史学 + 文化研究。

**L3 特化叠加**:

- **性别本体论**:性别如何被概念化——身份、表演、结构位置、生物-文化交叉?
- **历史化性别**:当前性别范畴是否被反读到使用不同范畴的历史材料中?
- **交叉性**:相关时,种族、阶级、性、能力等是否被视为交叉轴而非可加变量?

#### L3.8 · 后殖民研究

**继承**:文学 + 史学 + 文化研究。

**L3 特化叠加**:

- **位置性**:谁的声音被居中?谁的声音被理论化?不对称是否被承认?
- **翻译政治**:跨语言工作(尤其大都市 ↔ 边缘)时,翻译选择是否被标记为政治性?
- **抵抗欧洲中心主义**:章节用欧洲理论框架(福柯、德里达)读非欧材料?如是,引入代价是否讨论?

#### L3.9 · 环境人文

**继承**:文学 + 史学 + 科学。

**L3 特化叠加**:

- **人类纪框架**:援引人类纪(或资本世、种植园纪、克苏鲁纪)时,章节是在此辩论中取立场还是把某框架当中性?
- **多物种 / 超人类**:非人行动者被视为能动者、对象,还是依语境而定?
- **尺度问题**:章节工作在局部、区域,还是行星尺度?论证中的尺度跳跃是否辩护?

### 人文邻近领域(欢迎,带 scope 注释)

有些领域形式上归在社会科学,但包含强烈人文导向的子传统(文字本身就是论证)。本 skill 显式欢迎这类工作——以下方法论维度适用于这些领域的人文式子传统,**不适用于实证 / 量化子传统**。

#### 传播学 · 人文路径

**服务什么**:媒介环境学派(Innis · McLuhan · Postman · Carey · 多伦多传统);批判传播学;人文导向的文化-媒介研究;修辞学;传播哲学。

**不太适合**:实证 / 实验传播学;作为量化方法的内容分析;效果研究。(对这些工作,四层批判在散文层面仍可用,但以下学科特化维度不匹配。)

**继承**:媒介研究(L3.5)+ 哲学(L1.3)+ 文化研究(L3.1)。

**领域特化叠加**:

- **媒介即讯息的反思性**:做麦克卢汉式论证时,章节在自己的形式中是否体现其关于媒介的主张,还是与之矛盾?
- **思辨-实证的披露**:媒介环境学坦然是思辨的。章节不应在做思辨-哲学工作时伪装实证方法。
- **传统立场**:章节是 Innis 式(传播的偏向)、McLuhan 式(媒介-效果)、Postman 式(抵抗)、Carey 式(仪式观)?还是跨这些立场论证?

#### 教育学 · 人文路径

**服务什么**:教育史;教育哲学;人文模式的课程理论;批判教育学(Freire、hooks 等);重要思想家的教育思想。

**不太适合**:量化教育心理学;实证学习成效研究;评估研究。(对这些工作,四层批判在散文层面仍可用,但以下维度不匹配。)

**继承**:史学(L1.2)+ 哲学(L1.3)+ 文化研究(L3.1)。

**领域特化叠加**:

- **规范基础**:教育论证常涉规范主张(教育**应该**做什么?)。规范主张是被辩护的,还是被偷渡?
- **传统立场**:自由派、批判派、保守派、进步派?立场是否承认?
- **教育-社会链接**:把教育与社会关联(再生产、转型、流动、公民身份)时,机制是否阐明?

### 跨学科案例分析(附录——做案例研究时永远适用)

只要作者工作使用**案例研究**作为方法(任何 L1 / L2 / L3 / 邻近领域),以下维度**在已加载的学科特化维度之上叠加**适用:

- **案例选择代表性**:为什么选这些案例而不是其他?选择标准是否明确?
- **案例与理论的双向运动**:理论是否照亮了案例中不易看到的面向?案例是否修正或丰富了理论?还是案例只是理论的"插图"?
- **内部多样性**:不同案例之间是否存在张力?这些张力是否被利用来推进论证?
- **细节的分析价值**:叙述的细节是否服务于分析?还是有大段"百科全书式"介绍可删?
- **校准的概括**:从案例(s),概括什么——典型性、例外照亮规则、偏离案例重构理论?概括类型应明示。

### 兜底协议——作者学科不匹配任何 L1 / L2 / L3 / 邻近 entry 时

先从所供正文与作者已有说明中提取下列信息。只有某项无法合理判断且会改变分析时才询问：

1. **研究对象**:文本 / 过去事件 / 概念 / 现象 / 物件 / 语言结构 / 实践 / 制度 / 图像 / 声音 / 空间结构 / 其他(具体说明)
2. **主要方法**:文本细读 / 档案研究 / 论证分析 / 民族志 / 比较 / 语文学工作 / 结构分析 / 诠释分析 / 其他(具体说明)

说明最接近的 L1 与相关叠加,标为暂定的工作解释,随后继续已授权任务。项目配置属于任务范围时写入 `_writing-config/学科档案.md`,否则内联说明。不要求先批准缺失的档案才完成所请求的审读；不把推断分类写成作者已声明的身份。

如领域确实不匹配(如实时涌现的新学科),默认 L1 + 方法匹配,案例研究时加案例分析附录,并**显式告知作者这是最佳近似;建议作者随项目发展精细化声明**。
